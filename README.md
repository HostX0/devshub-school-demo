# School portal preview

An English interface preview of a school portal, using fictional school, student and parent information.

Explore student progress, attendance, notices and role-based dashboard journeys. The displayed demo password is a local interface simulation, not account security. Changes stay in the browser; this preview has no server, production database, real user accounts or messaging service.

## Run locally

Serve this folder with a static web server, or run `node build.mjs` and serve `dist`.
The build has no third-party package dependencies. It publishes only `index.html`, `app.js`, `styles.css` and approved files under `assets`.
